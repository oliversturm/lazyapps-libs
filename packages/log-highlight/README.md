# @lazyapps/log-highlight

Log output formatting and syntax highlighting for LazyApps. Enhances console output with color-coded log levels and structured data display.

## Installation

```bash
pnpm add @lazyapps/log-highlight
```

## Part of LazyApps

This package is part of the [LazyApps](https://github.com/oliversturm/lazyapps-libs) event-sourcing and CQRS framework.
