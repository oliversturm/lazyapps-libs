# @lazyapps/command-sender-fetch

HTTP-based command sender. Sends commands to a remote command processor service via HTTP fetch.

## Installation

```bash
pnpm add @lazyapps/command-sender-fetch
```

## Part of LazyApps

This package is part of the [LazyApps](https://github.com/oliversturm/lazyapps-libs) event-sourcing and CQRS framework.
